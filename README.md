# Self-Healing LLM Logs Pipeline

A resilient DataOps ingestion pipeline designed to intercept, repair, validate, and audit malformed JSON logs generated by Large Language Models (LLMs) in production. It proactively resolves issues like conversational text wrapping and structural truncation due to output token exhaustion.

## 🧠 Core Features

* **Heuristic JSON Healing (`src/healer.py`)**: Automatically sanitizes raw payloads using regular expressions to extract nested JSON blocks and applies structural correction (such as forced closing brackets) to un-truncated text streams.
* **Contract Enforcement (`src/validator.py`)**: Uses **Pydantic** schemas to validate incoming data structures against strict enterprise data contracts (`request_id`, `prompt`, `response_text`, `tokens_used`).
* **Relational Audit Trail (`src/database.py`)**: Persists successful clean logs in **SQLite** alongside telemetry data tracking their remediation status (`PERFECT`, `HEALED`) and the specific strategies used.

## 🛠️ Architecture & Tech Stack

* **Python 3.13+**
* **Pydantic** (Data validation engine)
* **SQLite3** (Auditing and local storage)
